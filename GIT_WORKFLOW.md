# Git Workflow

## Repository Management

The project follows a simple Git workflow.

## Branching

Main branch:
- Stable version of the pipeline

## Commit Strategy

Commits are created for:
- Feature implementation
- Bug fixes
- Documentation updates

## Commit Examples

Initial commit:
- Added medical image analysis pipeline

Feature commits:
- Added dataset validation
- Added image analysis
- Added visualization module

## Version Control

The repository tracks:
- Source code
- Configuration files
- Documentation

Generated files such as:
- Virtual environments
- Cache files
- Temporary outputs

are excluded using .gitignore.
